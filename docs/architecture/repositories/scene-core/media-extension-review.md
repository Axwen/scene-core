# 媒体扩展增量工程审查

日期：2026-09-14。范围：音频后置、分析抽帧、人物标注所需媒体边界；用户已确认三项推荐。本文不是音频或抽帧操作的完整 Spec。

## 结论与决策记录

1. Phase 0 保持工程/协议基础；Phase 1 只实现 probe 与固定诊断预览。音频和分析抽帧分别后置立项。
2. 用户已确认[素材时间规则](../../../specs/media-time-policy-draft.md)：容器展示原点、有符号轨道起点、有理数转换、明确舍入和异常处理；操作专用时间映射字段后置。
3. Core 管媒体，Seek 管分析调用与人物业务；分析模块先是逻辑职责，不新增服务或仓库。

三项由用户明确同意。未发布候选协议可修订；已被消费者固定的版本不能原地改变。

## Step 0 / What already exists

实际读取的 protocol 源码只有 `PROTOCOL_VERSION`，engine main 只引用该常量。没有可复用的音频、抽帧或人物实现；可复用的是既有身份、Manifest、取消/超时的规格。改动限定五份规划文档，不增加生产类、依赖或服务。

## Architecture Review

原 roadmap M1 和 responsibilities 首版仍包含音频，与 Spec 后置约定矛盾（P1，10/10）；已同步。Spec 原非负 startTimeMs 未解释原始 PTS 映射（P1，8/10）；用户已批准并同步精确时间规则，允许有符号轨道起点。诊断预览仅 opening/midpoint（P2，10/10），不能承担分析覆盖率承诺；未来独立抽帧操作。

```text
Seek：素材版本、人物目录、人工标注、检索
  | 调度请求 / 验证完整产物
  v
Core：probe + 诊断预览
  + 后续独立音频操作 -> 文件 + 原素材时间映射
  + 后续独立抽帧操作 -> 帧 + 请求/实际时间
  | 产物由 Host 管理
  v
Seek 分析模块：ASR/OCR -> 带来源的候选 -> 人工确认
```

人物标注不采用 TemporalSegment：它要求算法策略与来源，且语义是 shot/sceneCandidate。人工区间只复用半开区间规则，关联不可变素材版本；文字提及不自动等于出镜。分发继续使用平台 sidecar bundle；增加音频/抽帧能力时重验 codec 能力、许可和包依赖，不创建另一套分发体系。

## Code Quality Review

现有源码无音频封装或转换函数，不能把未来风险描述成代码缺陷。复用既有 DTO/Manifest 和派生键规格；禁止在 Seek 重建 FFmpeg 管理层，避免两套取消、工具版本和错误规则。职责说明的旧 input/output fingerprint 图已同步现行命名。

不建立空音频 crate、通用 DAG、模型 Provider 框架或自由 options。未来操作的有效参数必须进入派生键；ASR 模型版本和人物确认变化不污染 Core 媒体缓存身份。

## Failure Modes

| 路径 | 失败 | 要求的处理与证据 |
|---|---|---|
| 请求与快照 | 文件被替换 | 显式身份错误，拒绝输出；文件替换测试 |
| 时间归一化 | 音视频分别归零导致字幕错位 | 共享起点与偏移 fixture；无法映射时显式未知或失败 |
| 预览/抽帧 | 抽样没有覆盖人物或文字 | 不承诺完整覆盖；显示采样范围并允许人工补标 |
| 音频 | 无音轨、选错轨、时间跳变 | 操作规格定义稳定错误与修复动作，真实媒体测试 |
| 资源 | 磁盘满、超时、取消 | 不发布部分产物；进程级故障注入 |
| Host 发布 | 旧版本分析覆盖新素材 | current-result gate 与版本一致性测试 |
| 人工审核 | 重新分析覆盖人工确认 | 保留确认来源/修订，消费者 E2E |

这些处理均尚未实现；不得将规划表视为生产保障。时间规则决策已关闭；相关 DTO 与 fixture 必须按已确认规则实现，真实工具与播放器映射仍需后续集成验证。

## Performance Review

当前没有数据库查询，N+1 不适用；后续列表批量查询由 Seek 处理。Core 继续流式读取和文件产物，不把整段 PCM 或全部帧塞进 JSON/内存。Host 限制并发与队列，Core 限制单请求资源，不预建调度数据库。

后续抽帧必须有帧数/尺寸/字节预算；音频输出预算按时长×采样率×声道×样本字节数估算，并验证磁盘不足。实现时基准记录峰值内存、输出体积、解码吞吐和 P95 时延，不在没有样本与设备前承诺数值。批量抽帧避免逐帧重复完整解码，具体策略以基准决定。
